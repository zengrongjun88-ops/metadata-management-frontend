### 2. 验收路径建议

#### 第一步：元数据表管理（10分钟）
1. **查看表列表** - 默认页面显示10个表
   - 查看数据源多样性：Hive、BigQuery、ClickHouse、Paimon、Iceberg、StarRocks
   - 查看数仓分层：ODS、DWD、EDW、CDM、MID、DIM
   - 查看敏感等级：L1-L4

2. **搜索功能测试**
   - 搜索"user" → 应显示3个表（user_info、user_behavior_log、customer_profile）
   - 搜索"order" → 应显示2个表
   - 搜索"payment" → 应显示1个表

3. **高级筛选测试**
   - 数据源选择"Hive" → 显示6个表
   - 分层选择"DWD" → 显示4个表
   - 敏感等级选择"L1" → 显示4个表

4. **查看表详情**
   - 点击"user_info"表名
   - 查看基础信息（表名、库名、数据源、描述、敏感等级等）
   - 查看字段列表（6个字段，含主键、加密、敏感等级）

5. **创建新表**
   - 点击"新建表"按钮
   - 填写表信息（表名、库名、数据源等）
   - 添加字段（字段名、类型、描述等）
   - 生成SQL并查看
   - 校验SQL
   - 创建表
   - 返回列表查看新表（ID=11）

#### 第二步：审批管理（5分钟）
1. **查看审批列表**
   - 点击左侧菜单"审批管理"
   - 查看6个审批单
   - 观察不同状态的标签颜色

2. **筛选测试**
   - 状态筛选"待审批" → 显示1条
   - 状态筛选"已通过" → 显示2条
   - 状态筛选"已发布" → 显示1条

3. **审批操作**
   - 找到待审批单据（APPR-2024-001）
   - 点击"审批"按钮
   - 填写审批人和意见
   - 点击"通过"
   - 观察状态变更

4. **发布变更**
   - 找到已通过的审批单
   - 点击"发布"按钮
   - 观察状态变更为"已发布"

#### 第三步：操作历史（3分钟）
1. **查看历史列表**
   - 点击左侧菜单"操作历史"
   - 查看10条历史记录
   - 观察操作类型标签（CREATE、UPDATE）

2. **筛选测试**
   - 操作类型筛选"CREATE" → 显示6条

3. **查看变更详情**
   - 点击某条UPDATE记录的"查看详情"
   - 查看变更前后的JSON对比

## 🔧 Mock模式切换

### 开启Mock模式（当前状态）
```typescript
// src/constants/index.ts
export const USE_MOCK = true;
```

### 切换到真实API
```typescript
// src/constants/index.ts
export const USE_MOCK = false;
```

修改后需要：
1. 确保后端服务运行在 http://localhost:8080
2. 刷新浏览器页面

## 🐛 已知限制

1. **Mock数据持久化**：刷新页面后，新增/修改的数据会丢失（这是正常的，因为数据存储在内存中）
2. **SQL校验**：只做简单的关键字检查，不做完整的语法解析
3. **权限控制**：Mock模式下没有真实的权限验证

## 💡 验收建议

### 推荐验收顺序
1. 先验收**表查询功能**（最基础）
2. 再验收**表创建功能**（创建一个新表）

- 查看Console面板，确认没有JavaScript错误
- 查看Network面板，观察Mock API的调用（会直接返回，无网络请求）
